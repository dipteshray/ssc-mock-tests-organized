1. The central angle of a sector is 80º and whose length is 96π. What is the radius of the circle?

A. 196 units

B. 204 units

C. 116 units

D. 216 units

Answer D

Solution

96π = (80 / 360) × 2πr ⇒ 96 = (4r / 9) ⇒ r = 216 units.

2. If a : b = c : d = e : f = 5 : 7, then what is the ratio (3a + 5c + 11e) : (3b + 5d + 11f)?

A. 7 : 11

B. 3 : 7

C. 5 : 7

D. 11 : 7

Answer C

Solution

a = 5k, b = 7k, c = 5m, d = 7m, e = 5n, f = 7n ⇒ (3a + 5c + 11e) : (3b + 5d + 11f) = (3(5k) + 5(5m) + 11(5n)) : (3(7k) + 5(7m) + 11(7n)) ⇒ (15k + 25m + 55n) : (21k + 35m + 77n) ⇒ [5(3k + 5m + 11n)] : [7(3k + 5m + 11n)] = 5 : 7

A. 200

B. 150

C. 170

D. 190

Answer A

Solution

C. (1/p + 1)

D. p - 1

Solution

23. Suresh's expenditure and savings are in the ratio of 3 : 1. His income increases by 25%. If his savings increase by 20%, then by how much percentage does his expenditure increase?

A. 27 (2)/(3)%

B. 25 (2)/(3)%

C. 28 (2)/(3)%

D. 26 (2)/(3)%

Answer D

Solution

Let original income be 4x. Expenditure = 3x, Savings = x. New income = 4x + 25%(4x) = 5x New savings = x + 20%(x) = 1.2x. New expenditure = 5x - 1.2x = 3.8x. Percentage increase in expenditure = [(3.8x - 3x) / 3x] × 100 = 262/3%.
