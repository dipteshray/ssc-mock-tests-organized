1. The salaries of P and Q together amount to ₹9,60,000. P and Q save 64% and 44%, respectively of their individual salaries. If P's expenditure is 1.5 times Q's expenditure, then what is the ratio of P's salary to Q's salary?

A. 2 : 3

B. 7 : 3

C. 3 : 7

D. 3 : 2

Answer B

Solution

P + Q = 9,60,000 ⇒ P saves 0.64P, Q saves 0.44Q ⇒ P's expenditure = 0.36P, Q's expenditure = 0.56Q ⇒ P's expenditure = 1.5 × Q's expenditure ⇒ 0.36P = 1.5 × 0.56Q ⇒ P / Q = 0.84 / 0.36 ⇒ P / Q = 7 / 3 ⇒ P + Q = 9,60,000 ⇒ 7x + 3x = 9,60,000 ⇒ x = 96,000, ⇒ P = 7 × 96,000 = 6,72,000, Q = 3 × 96,000 = 2,88,000 ⇒ P / Q = 7 / 3

Solution

11. The simple interest on a sum for 6 years is three-fifth of the sum. The rate of interest per annum is:

A. 3%

B. 7%

C. 10%

D. 5%

Answer C

Solution

SI = (P × R × 6) / 100 ⇒ (3/5)P = (P × R × 6) / 100 ⇒ 3 × 100 = R × 6 × 5 ⇒ R = 300 / 30 ⇒ R = 10%.

17. Find the values of 'a' and 'b' for which the system of equations 3x + y = 3 and (a - b)x + (a + b)y = 3a + b - 3 has infinite solutions.

A. a = 3, b = -2/3

B. a = -3/2, b = 2

C. a = 3, b = -3/2

D. a = 2, b = -3/2

Answer C

Solution

(3)/(a - b) = (1)/(a + b) ⇒ 3(a + b) = a - b ⇒ 2a + 4b = 0 ⇒ a = -2b ⇒ (1)/(a + b) = (3)/(3a + b - 3) ⇒ b - 3 = 3b ⇒ b = -3/2 ⇒ a = -2b ⇒ a = 3
