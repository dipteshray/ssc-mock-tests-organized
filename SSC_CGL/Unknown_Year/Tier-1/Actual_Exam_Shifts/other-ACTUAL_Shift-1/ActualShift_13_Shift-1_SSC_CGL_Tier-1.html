1. If A : B = 4 : 5, B : C = 10 : 7, and C : D = 14 : 15, find the combined ratio A : B : C : D.

A. 16 : 20 : 14 : 15

B. 8 : 10 : 7 : 15

C. 16 : 20 : 7 : 15

D. 4 : 5 : 7 : 15

Answer A

Solution

A : B = 4 : 5, B : C = 10 : 7 ⇒ Make B equal: A : B = 8 : 10 (×2) B : C = 10 : 7, C : D = 14 : 15 ⇒ Make C equal: B : C = 20 : 14 (×2), A : B = 16 : 20 (×2) ⇒ A : B : C : D = 16 : 20 : 14 : 15

2. A collection box contains 5, 2, and 1 coins in the ratio 4 : 3 : 2. If the total value in the box is 280, determine the number of coins of each denomination respectively.

A. 40, 30, 20

B. 30, 40, 20

C. 20, 30, 40

D. 40, 20, 30

Answer A

Solution

Let the number of coins be 4x, 3x, and 2x for 5-unit, 2-unit, and 1-unit coins, respectively. ⇒ Total value = (4x × 5) + (3x × 2) + (2x × 1) ⇒ 280 = 20x + 6x + 2x ⇒ 280 = 28x ⇒ x = 280 ÷ 28 = 10 ⇒ Number of 5-unit coins = 4x = 40, Number of 2-unit coins = 3x = 30, Number of 1-unit coins = 2x = 20

B. Profit of 200

C. Profit of 300

D. Loss of 300

Answer C

Solution

Answer B

Solution

D. 30 percent

Answer C

Solution
