1. If the unit digit of 433 × 456 × 43N is (N + 2), then what is the value of N?

A. 1

B. 8

C. 3

D. 6

Answer D

Solution

Shortcut Trick Unit digit of product = Unit digit of (3 × 6 × N) = Unit digit of (18 × N) = Unit digit of (8 × N). Given that the unit digit is (N + 2), we check the options for the condition: UD(8 × N) = N + 2. Testing N = 6: Unit digit of (8 × 6) = Unit digit of 48 = 8. Value of (N + 2) = 6 + 2 = 8. Since 8 = 8, the condition is satisfied when N = 6. ∴ The correct answer is 6. Alternate Method Given: Numbers: 433, 456, 43N Product: 433 × 456 × 43N Unit digit of product = N + 2 Formula Used: The unit digit of a product depends only on the unit digits of the numbers being multiplied. Calculations: ⇒ Unit digit of 433 = 3 ⇒ Unit digit of 456 = 6 ⇒ Unit digit of 43N = N ⇒ Unit digit of (433 × 456 × 43N) = Unit digit of (3 × 6 × N) ⇒ Unit digit of (18 × N) = Unit digit of (8 × N) ⇒ According to the question: Unit digit of (8 × N) = N + 2 ⇒ If N = 1: UD(8 × 1) = 8; N + 2 = 3 (8 ≠ 3) ⇒ If N = 3: UD(8 × 3) = 4; N + 2 = 5 (4 ≠ 5) ⇒ If N = 8: UD(8 × 8) = 4; N + 2 = 10 → UD = 0 (4 ≠ 0) ⇒ If N = 6: UD(8 × 6) = 8; N + 2 = 8 (8 = 8) ⇒ Since the condition is satisfied for N = 6, the value of N is 6. ∴ The correct answer is 6. Additional Information Unit Digit of Powers (Cyclicity) The unit digit of any number raised to a power repeats in a cycle. For digits 2, 3, 7, and 8, the cyclicity is 4; for 4 and 9, it is 2; and for 0, 1, 5, and 6, it is 1. Product Unit Digit Rule To find the unit digit of a large product, multiply only the unit digits of the individual factors. The unit digit of the final product will be the unit digit of this multiplication. Special Case for 5 If any factor in a product has a unit digit of 5 and there is at least one even number in the product, the unit digit of the entire product will always be 0.

B. 10/11

Solution

In a telescoping sum, all intermediate terms cancel out, leaving only the first and last parts. Sum = First part of f(1) − Last part of f(10) = 1/1 − 1/11. Sum = 10/11. ∴ The correct answer is 10/11. 95. What is the value of cos15° - cos165°?

A. √3/√2

B. 2/ (√3 - 1)

C. (√3 + 1) /√2

Answer C

Solution

Shortcut Trick Using the trigonometric identity: cos(180° − θ) = −cos θ. Therefore, cos 165° = cos(180° − 15°) = −cos 15°. The expression becomes cos 15° − (−cos 15°) = 2 cos 15°. Given cos 15° = (√3 + 1) / (2√2), the value is 2 × [(√3 + 1) / (2√2)]. ∴ The correct answer is (√3 + 1) / √2. Alternate Method Given: cos 15° − cos 165° Formula Used: cos C − cos D = 2 sin((C + D) / 2) sin((D − C) / 2) ⇒ cos 15° − cos 165° = 2 sin((15° + 165°) / 2) sin((165° − 15°) / 2) ⇒ = 2 sin(180° / 2) sin(150° / 2) ⇒ = 2 sin 90° sin 75° ⇒ Since sin 90° = 1 and sin 75° = cos 15° ⇒ = 2 × 1 × [(√3 + 1) / (2√2)] ⇒ = (√3 + 1) / √2 ∴ The correct answer is (√3 + 1) / √2. Additional Information Supplementary Angle Identities cos(180° − θ) = −cos θ and sin(180° − θ) = sin θ. This is because in the second quadrant, cosine is negative while sine is positive.
