1. What is the unit digit of the sum of first 111 whole numbers?

A. 4

B. 6

C. 5

D. 0

Answer C

Solution

Shortcut Trick Whole numbers start from 0. The first 111 whole numbers are 0, 1, 2, ..., 110. Sum of first n natural numbers = [n × (n + 1)] ÷ 2. The sum of (0 to 110) is the same as the sum of (1 to 110). Sum = [110 × (110 + 1)] ÷ 2 = 55 × 111. Unit digit = Unit digit of (5 × 1) = 5. ∴ The correct answer is 5. Alternate Method Given: First 111 whole numbers (0, 1, 2, 3, ..., 110). Formula Used: Sum of an Arithmetic Progression (AP) = (n ÷ 2) × [first term + last term]. ⇒ First term (a) = 0 ⇒ Last term (l) = 110 ⇒ Number of terms (n) = 111 ⇒ Sum = (111 ÷ 2) × (0 + 110) ⇒ Sum = 111 × (110 ÷ 2) ⇒ Sum = 111 × 55 ⇒ Sum = 6105 ⇒ The unit digit is 5. ∴ The correct answer is 5. Additional Information Whole Numbers vs Natural Numbers Whole numbers include 0 (0, 1, 2...), while natural numbers start from 1 (1, 2, 3...). The first n whole numbers always end at (n − 1). Sum of First n Odd/Even Numbers Sum of first n odd numbers = n2. Sum of first n even numbers = n(n + 1). Unit Digit Rules To find the unit digit of a sum or product, only perform the operation on the unit digits of the individual numbers.

8. N is the largest two-digit number, which when divided by 3, 4 and 6 leaves the remainder 1, 2 and 4 respectively. What is the remainder when N is divided by 5?

B. 2

D. 1

Answer A

Solution

Shortcut Trick Common difference (d) = Divisor − Remainder d = (3 − 1) = (4 − 2) = (6 − 4) = 2 General form: N = [LCM(3, 4, 6) × k] − 2 LCM(3, 4, 6) = 12 ⇒ N = 12k − 2 Largest 2-digit N (where k=8) = 12 × 8 − 2 = 94 Remainder of 94 ÷ 5 = 4 ∴ The correct answer is 4. Alternate Method Given: Divisors are 3, 4, and 6. Respective remainders are 1, 2, and 4. 10. A and B are positive integers. If A + B + AB = 65, then what is the difference between A and B (A, B ≤ 15)?

A. 3

B. 4

C. 5

D. 6

Answer C

Solution

Shortcut Trick Use Simon's Favorite Factoring Trick: A + B + AB + 1 = (A + 1)(B + 1). Given A + B + AB = 65, adding 1 to both sides gives (A + 1)(B + 1) = 66. Find factors of 66 such that both are ≤ 16 (since A, B ≤ 15): 6 × 11. A + 1 = 6 → A = 5; B + 1 = 11 → B = 10. Difference = |10 − 5| = 5. ∴ The correct answer is 5. Alternate Method Given: A + B + AB = 65 and A, B ≤ 15 (Positive integers). Formula Used: (A + 1)(B + 1) = AB + A + B + 1 ⇒ A + B + AB = 65 ⇒ (A + B + AB) + 1 = 65 + 1 ⇒ A(1 + B) + 1(1 + B) = 66 ⇒ (A + 1)(B + 1) = 66 ⇒ Possible integer pairs for (A+1, B+1) such that A, B ≤ 15: ⇒ Case 1: 1 × 66 (Invalid, 66 > 16) ⇒ Case 2: 2 × 33 (Invalid, 33 > 16) ⇒ Case 3: 3 × 22 (Invalid, 22 > 16) ⇒ Case 4: 6 × 11 (Valid, both 6 and 11 ≤ 16) ⇒ Let A + 1 = 6 ⇒ A = 5 ⇒ Let B + 1 = 11 ⇒ B = 10 ⇒ Difference |A − B| = |5 − 10| = 5 ∴ The correct answer is 5. A. 196

C. 206

D. 182

Answer B

Solution

The correct answer is 194 Key Points Additional Information

• Given the value P = 7 + 4√3 and the condition PQ = 1, we can determine that Q = 1/P.

• The expression to evaluate is 1/P2 + 1/Q2. Substituting 1/P = Q and 1/Q = P, the expression simplifies to Q2 + P2.

• To find the value of Q, we rationalize the reciprocal of P: Q = 1 / (7 + 4√3). Multiplying the numerator and denominator by the conjugate (7 − 4√3): Q = (7 − 4√3) / ((7 + 4√3)(7 − 4√3)) Q = (7 − 4√3) / (72 − (4√3)2) Q = (7 − 4√3) / (49 − 48) = 7 − 4√3.

• Now, calculate the sum of P and Q: P + Q = (7 + 4√3) + (7 − 4√3) = 14.

• Using the algebraic identity P2 + Q2 = (P + Q)2 − 2PQ: Substitute P + Q = 14 and PQ = 1: P2 + Q2 = 142 − 2(1) P2 + Q2 = 196 − 2 = 194.

• Therefore, the value of 1/P2 + 1/Q2 is 194.

• Rationalization is a fundamental technique in algebra used to remove radicals (like square roots) from the denominator of a fraction.

• The Conjugate of an expression a + √b is a − √b. Multiplying these together results in a rational number: a2 − b.
