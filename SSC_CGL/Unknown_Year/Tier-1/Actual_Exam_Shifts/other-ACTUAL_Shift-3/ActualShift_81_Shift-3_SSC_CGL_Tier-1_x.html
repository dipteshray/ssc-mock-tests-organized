1. If the altitude from two vertices of a triangle to the opposite sides are equal, then the triangle will be:

A. Isosceles triangle

B. Equilateral triangle

C. Scalene triangle

D. Obtuse angle triangle

Answer A

Solution

Altitudes from two vertices to the opposite sides are equal. In an isosceles triangle, altitudes from equal sides are equal. ∴ Triangle is isosceles.

5. The monthly incomes of A, B and C are in the ratio 2 : 9 : 3 and their expenses are in the ratio 3 : 9 : 5. If A’s saving is half of his total income, then savings of A, B and C are, respectively, in the ratio of:

A. 3 : 9 : 2

B. 2 : 5 : 2

C. 3 : 18 : 4

D. 1 : 2 : 1

Answer C

Solution

Let incomes of A, B, C be 2x, 9x, 3x and expenses be 3y, 9y, 5y respectively. A's saving = 2x/2 = x For A: x = 2x - 3y ⟹ y = x/3 For B: Savings = 9x - 9y = 9x - 3x = 6x For C: Savings = 3x - 5y = 3x - 5(x/3) = (9x - 5x)/3 = 4x/3 Ratio = x : 6x : 4x/3 ⟹ 3 : 18 : 4

6. A tank is filled in 45 minutes by two pipes, A and B. Pipe B fills the tank twice as fast as A. How much time (in minutes) will pipe A alone take to fill the tank?

A. 135

B. 140

C. 125

D. 115

Answer A

Solution

Let the time taken by pipe A alone to fill the tank be x minutes Rate of filling of pipe A = 1/x Rate of filling of pipe B = 2/x Combined rate = 1/x + 2/x = 3/x Given combined rate = 1/45 ⇒ 3/x = 1/45 ⇒ x = 3 × 45 ⇒ x = 135 minutes

8. The greatest value of sin4θ + cos4θ is:

A. 2

B. 1

C. 3

D. 4

Answer B

Solution

sin4(θ) + cos4(θ) = (sin2(θ) + cos2(θ))2 - 2 sin2(θ) cos2(θ) ⇒ sin2(θ) + cos2(θ) = 1 ⇒ sin2(θ) cos2(θ) = (1/2 sin(2θ))2 = 1/4 sin2(2θ) ⇒ sin4(θ) + cos4(θ) = 1 - 1/2 sin2(2θ) Max value at θ = 0 ⇒ sin4(θ) + cos4(θ) = 1 - 0 = 1

A. 2

B. 1

C. 3

D. 0

Answer B

Solution

x = a secθ cosφ, y = b secθ sinφ, z = c tanθ Calculate (x2/a2 + y2/b2 - z2/c2): ⇒ (a2 sec2θ cos2φ)/a2 + (b2 sec2θ sin2φ)/b2 - (c2 tan2θ)/c2, sec2θ cos2φ + sec2θ sin2φ - tan2θ ⇒ sec2θ (cos2φ + sin2φ) - tan2θ ⇒ sec2θ - tan2θ = 1.

21. Find the value of the unknowns: x + 1.5y + 2z = 5.5 x + 5y + 7z = 15 3x + 11y + 13z = 25

A. x = 2,y = -3,z = 4

B. x = -3,y = 2,z = 4

C. x = 4,y = -3,z = 2

D. x = 2,y = 4,z = -3

Answer A

Solution

x + 1.5y + 2z = 5.5, x + 5y + 7z = 15, 3x + 11y + 13z = 25 From x + 1.5y + 2z = 5.5, x = 5.5 - 1.5y - 2z Substitute x in x + 5y + 7z = 15 ⇒ (5.5 - 1.5y - 2z) + 5y + 7z = 15 ⇒ 3.5y + 5z = 9.5 ⇒ y = (9.5 - 5z) / 3.5 Substitute x in 3x + 11y + 13z = 25 ⇒ 3(5.5 - 1.5y - 2z) + 11y + 13z = 25 ⇒ 6.5y + 7z = 8.5 ⇒ y = (8.5 - 7z) / 6.5 Equate y equations: (9.5 - 5z) / 3.5 = (8.5 - 7z) / 6.5 ⇒ 6.5(9.5 - 5z) = 3.5(8.5 - 7z) ⇒ 32 - 8z = 0 ⇒ z = 4 Substitute z in y equation, y = (9.5 - 20) / 3.5 ⇒ y = -3 Substitute y and z in x equation, x = 5.5 + 4.5 - 8 ⇒ x = 2 The correct answer is: x = 2, y = -3, z = 4
