Solution

Given: The first puncture alone would have made the tyre flat in 45 minutes The second puncture alone would have done it in 90 minutes. Concept used: Total work = Efficiency of an object × time taken by the object Calculation: LCM of 45 and 90 = 90 units i.e total work So, efficiency of 1st puncture = 90/45 = 2 units/min efficiency of 2nd puncture = 90/90 = 1 unit/min Effective efficiency of both the puncture = 3 units/min Time taken to flat the tyre by both the puncture = 90/3 ⇒ 30 min ∴ It takes 30 (in minutes) for both the punctures together to make the tyre flat.

50. If a + b = 3 and ab = 2, then what is the value of 2a3 + 2b3?

A. 25

B. 27

C. 18

D. 20

Answer C

Solution

Given a + b = 3 ab = 2 Concept: This is the formula to simplify cubic expressions: a³ + b³ = (a + b)(a² - ab + b²) Solution: 2a³ + 2b³ = 2(a³ + b³) 2(a + b)(a² - ab + b²) (Substituting from given) 2(3)(a² - 2 + b²) (as a + b = 3 and ab = 2) 2(3)(a² + b² - 2) (as a² + b² = (a + b)² - 2ab = 9 - 4 = 5) 2(3)(5 - 2) = 2(3)(3) = 18 fore, the value of 2a³ + 2b³ is 18.
