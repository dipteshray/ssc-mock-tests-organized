13. In MS-Word 365, what is the primary difference between the ‘Save’ and ‘Save As’ commands?

A. ‘Save’ is used to save the document with a new filename or in a different location, while ‘Save As’ is used to save the document for the first time.

B. ‘Save’ is used to save the document in the cloud storage, while ‘Save As’ is used to save the document on the local computer.

C. ‘Save’ is used to save the document for the first time, while ‘Save As’ is used to save the document with a new filename or in a different location.

D. Both ‘Save’ and ‘Save As’ perform the same function of saving the document; they are just two different names for the same command.

Answer C

Solution

The correct answer is ‘Save’ is used to save the document for the first time, while ‘Save As’ is used to save the document with a new filename or in a different location. Key Points

• Save: This command updates the existing file with the current changes. It overwrites the previous version of the file, effectively replacing it with the latest modifications. This is typically used for ongoing work on a document, where you want to preserve the most recent changes to the same file.

• Save As: This command creates a new copy of the file, allowing you to save it under a different name or in a different location. This preserves the original file intact while creating a separate version of the document. This is useful when you want to:

• Create a backup: Save a copy of the file for safekeeping.

• Save different versions: Maintain multiple versions of the document with different modifications.

• Change the file format: Save the document in a different format (e.g., PDF, RTF, or DOCX).

• Save the file in a different location: Move the file to a different folder or drive.

• In essence: Save: Updates the existing file.

• Save As: Creates a new copy of the file.

23. Which of the following occupies less memory when saving an MS-Word file?

B. docm

C. doc

D. docc

Answer A

Solution

The docx file format, introduced in Microsoft Word 2007, is a compressed, XML-based format that occupies less memory compared to other MS-Word file formats. This makes it more storage-efficient and improves data recovery options. Unlike the older doc format, which is larger due to lack of compression, docx files are smaller and more efficient for storage and sharing. The docm format, which includes macros, can be larger than docx. The docc format is not a standard MS-Word file format. Converting older doc files to docx can help save storage space and improve compatibility.

• Subscript and Superscript: Subscript: Text appears below the baseline, often used in formulas (e.g., H2O).

• Superscript: Text appears above the baseline, commonly used in exponents (e.g., x2).

• Shortcut for Superscript: Use Ctrl + Shift + = to apply superscript formatting in MS Word.

• Other Formatting Shortcuts: Ctrl + B: Bold text.

• Ctrl + I: Italicize text.

• Ctrl + U: Underline text.

• Customizing Shortcuts: MS Word allows users to customize shortcut keys through the "Customize Ribbon" and "Keyboard Shortcuts" options in the settings.

• Accessibility: Shortcut keys help improve accessibility for users who rely on keyboard navigation or have limited use of a mouse.
