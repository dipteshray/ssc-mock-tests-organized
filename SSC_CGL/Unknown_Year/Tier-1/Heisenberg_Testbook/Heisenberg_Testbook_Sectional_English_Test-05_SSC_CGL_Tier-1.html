1. Which of the following is NOT correct regarding Malwares?

A. A Virus infects other programs by modifying them to include a possibly evolved copy of itself.

B. Worms copy themselves from system to system, rather than infiltrating legitimate files.

C. Trojans are used to create back-doors on computers belonging to a secure network.

D. Hoax invades a computer and monitors a user’s activities without consent.

Answer D

Solution

Option 4 is NOT correct. Key Points Malware:

• Software designed to perform an unwanted illegal act via the computer network.

• Can be classified on the basis of execution: Virus: Infects other programs by modifying them to include a possibly evolved copy of itself.

• Worm: Copy themselves from system to system, rather than infiltrating legitimate files.

• Trojan: Impairs the security of a system and is used to create back-doors on computers belonging to a secure network.

• Hoax: It invades the system and deletes an important file when a program is run to correct the harming system.

• Spyware: Invades a computer and monitors a user’s activities without consent. So, option 4 is NOT correct.

5. The time required to move the read/write head to the desired track of a disk is called

A. Latency

B. Access time

C. Seek time

D. page fault

Answer C

Solution

The correct answer is option (3) Concept:- Seek time:- The seek time is the time it takes for the read/write head of the disc to move from one part of the disc to another. Key Points Additional Information Access time:- It's the time it takes for a computer to request data and then for that request to be fulfilled. Memory, hard drives, CD-ROMs, and other mechanisms are all affected by access time. Latency:- Rotational time is another name for rotational latency. The interval between information requests and the hard disc moving to the right sector is known as the rotational delay. Page fault:- When a software tries to access data or code that is in its address space but not already in the system RAM, a page fault occurs.

• The time it takes a hard disc controller to locate a specific piece of stored data is known as seek time.

• The read/write head of the disc must move to the correct location when anything is read or written to it. Seeking refers to the physical placement of the disk's read/write head.

• Due to the changing distance between the start point and where the read/write head has been directed to proceed, the seek time for a particular disc might vary.

• The average seeks time is commonly used to measure seek time. Track to track and entire stroke are two more ways to quantify seek time.

9. Which of the following is not true about a Modem?

A. Modem is a device which modulates / demodulates carrier waves with digital information to transmit the data

B. Modems are measured in terms of speed by the amount of data they can send in a given unit time ­eg. bits per second.

C. A modem shares the internet connection with multiple devices by dispatching packets of information

D. The modem communicates with the Internet Service Provider

Answer C

Solution

The correct answer is a modem shares the internet connection with multiple devices by dispatching packets of information. Key Points

• A modem is a network device that both modulates and demodulates analog carrier signals (called sine waves) for encoding and decoding digital information for processing.

• Modems accomplish both of these tasks simultaneously and, for this reason, the term modem is a combination of "modulate" and "demodulate."

• Modem speeds are typically measured in bits per second.

• The modem takes signals from your ISP and translates them into signals your local devices can use, and vice versa.

Solution
