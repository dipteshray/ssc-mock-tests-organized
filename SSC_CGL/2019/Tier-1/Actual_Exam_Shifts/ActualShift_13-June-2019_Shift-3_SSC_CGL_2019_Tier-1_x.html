A. + and -

B. + and ÷

C. × and -

D. ÷ and ×

Answer D

Solution

Given equation :-20 ÷ 20 + 20 – 25 × 25 = 419 1) Interchanging + and -, Equation will become :- 20 ÷ 20 - 20 + 25 × 25 = 1 – 20 + 625 ≠ 419 2) Interchanging + and ÷ Equation will become :- 20 + 20 ÷ 20 – 25 × 25 20 + 1 – 625 ≠ 419 3) Interchanging × and – Equation will become :- 20 ÷ 20 + 20 × 25 - 25 = 1 + 500 - 25 ≠ 419 4) Interchanging ÷ and × Equation will become :- 20 × 20 + 20 – 25 ÷ 25 = 400 + 20 – 1 = 419 Thus, interchanging “÷ and ×” we get the correct answer.

45. If x + 1/x = 5, then x3 + 1/x3 is equal to:

A. 125

B. 130

C. 110

D. 145

Answer C

Solution

Shortcut Trick For an algebraic expression of the form x + 1/x = k, the value of x3 + 1/x3 is calculated as k3 − 3k. Given that x + 1/x = 5, we have k = 5. ⇒ Value = 53 − 3 × 5 ⇒ Value = 125 − 15 = 110. ∴ The correct answer is 110. Alternate Method Given: x + 1/x = 5 Formula Used: The algebraic identity for the cube of a binomial: (a + b)3 = a3 + b3 + 3ab(a + b) Calculations: Cubing both sides of the given equation: ⇒ (x + 1/x)3 = 53 ⇒ x3 + (1/x)3 + 3 × x × (1/x) × (x + 1/x) = 125 ⇒ x3 + 1/x3 + 3 × 1 × (x + 1/x) = 125 Substituting the value of (x + 1/x) = 5: ⇒ x3 + 1/x3 + 3(5) = 125 ⇒ x3 + 1/x3 + 15 = 125 ⇒ x3 + 1/x3 = 125 − 15 ⇒ x3 + 1/x3 = 110 Therefore, the correct option is 3. ∴ The correct answer is 110. Additional Information Square Identity If x + 1/x = k, then x2 + 1/x2 = k2 − 2. Negative Sign Identity (Cube) If x − 1/x = k, then x3 − 1/x3 = k3 + 3k. Negative Sign Identity (Square) If x − 1/x = k, then x2 + 1/x2 = k2 + 2. Higher Powers To find x4 + 1/x4, square the result of x2 + 1/x2 and subtract 2.

51. ABCD is a cyclic quadrilateral such that AB is the diameter of the circle circumscribing it and ∠ADC = 129°. Then, ∠BAC is equal to:

A. 51°

B. 39°

C. 61°

D. 49°

Answer B

Solution

Given ABCD is a cyclic quadrilateral, and ∠ADC = 129° As we know, the sum of the either pair of the opposite angles of a cyclic quadrilateral is 180°. ⇒ ∠ADC + ∠ABC = 180 ⇒ ∠ABC = 180° – 129° = 51° In ΔACB, if AB is diameter, then ∠ACB = 90° ⇒ ∠ACB + ∠ABC + ∠BAC = 180° ⇒ 90° + 51° + ∠BAC = 180° ⇒ ∠BAC = 180° – 90° – 51° = 39°
